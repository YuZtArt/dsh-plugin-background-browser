插件提供独立会话浏览器、同一浏览器的侧栏画面及人工接管，接管期间阻止 agent 的后续浏览器操作。它有自己的会话管理、HTTP 交互和 UI，不是只列依赖的聚合包。是否与现有收录重复由维护者结合实际功能判断。

当前验证为真实 DSH rc.2 服务、浏览器和测试环境客户端组件，未宣称完整 Desktop 2.0.10 端到端验证。建议投稿前确认实际桌面端的安装、侧栏入口、登录接管与交还流程；不要在描述中承诺未验证功能。

Release 链接钉住版本标签，不使用带版本文件名的 latest/download 链接。更新安装包时同步本条目的 tarball。
